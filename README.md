# 📚 Library Management System (Python)

## 📌 Project Description
This is a simple Library Management System built using Python.  
It allows users to add books, issue books to students, return books, and calculate fines for late returns.

---

## ⚙️ Features

- 📖 Show all available books
- ➕ Add new books to the library
- 📤 Issue books to students
- 🔁 Return books
- 💰 Automatic fine calculation for late returns
- 🧑 Student name tracking
- 📅 Issue date and due date management

---

## 💰 Fine System

If a book is returned late, the fine is calculated as:

- Week 1 → ₹10 per day per book  
- Week 2 → ₹20 per day per book  
- Week 3 → ₹60 per day per book  
- And continues in increasing pattern

## 🧠 Concepts Used

- Python Dictionaries

- Date and Time handling

---

## 🗂️ Project Structure

- main.py → Main menu system  
- add_book.py → Add new books  
- issue_book.py → Issue books to students  
- return_book.py → Return books and calculate fine  
- show_books.py → Display books  
- utils.py → Date handling functions  
- fine.py → Fine calculation logic  
- data.py → Stores book data
